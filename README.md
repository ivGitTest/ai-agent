# А҆́и-а҆ге́нтъ

Сі́й проє́ктъ є҆́сть и҆скꙋ́ственный ᲂу҆́мъ (а҆́и), ꙗ҆́же съꙗ҆́ꙁь творѧ́етъ съ гꙋ́рвой Открꙋ́терꙿ и҆ бесѣ́дꙋетъ съ чл҃вѣ́комъ є҆́гоже вопр̑о́сы слы́шитъ.

## Лѣ́та и҆ ѡ҆рꙋ҄дїѧ

- Пѷѳо́нъ 3
- langchain-openrouter
- langchain-core
- environs

## ᲂУ҆строе́нїе

Пре́жде нача́тїѧ да́ждь ꙗ҆́звѣ́ли́чь створѧ̀ть:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Со́творѝ въ ко́рнѣ проє́кта фа́йлъ `.env` и҆ впи́ши та́мо:

```
openrouter-api-key=тво́й_клѧчъ_ꙗ҆́ко
```

## Нача́тїе

```bash
python main.py
```

О҆́баче въ речꙋ́ ве́деши нал́и́къ сво́й въ консо́лѣ, а҆́и же ѻ҆твѣ́тъ свои̑й рече́тъ. Вѣ́си, ꙗ҆́ко о҆твѣ́ти кра́тцы сꙋ́ть — трѝ и҆лѝ пѧ́ть предложе́нїй.

## Ꙗ҆́коже дѣ́йствꙋ́етъ

1. Из̾ `.env` поїе́млетсѧ клѧ́чъ гꙋ́рвы Открꙋ́терꙿ.
2. Сꙋ́творѧ́етсѧ слове́сникъ (модє́ль) `openrouter/free`.
3. Чл҃вѣ́къ пи́шетъ вопр̑о́съ.
4. Сло́во си́стемы и҆ вопр̑о́съ чл҃вѣ́чь посыла́ютсѧ въ модє́ль.
5. Ꙗ҆́ви́тсѧ о҆твѣ́тъ модє́ли.

## Зр̑ѧ̀

Сі́е скро́мное нача́ло ꙗ҆́же прє́жде дн҃й и҆мꙋ́ще въ по́мыслѣ — пода́ждь вопр̑о́сы lòка́льнѣ ве́стемъ и҆ творѝ ла́дь нова́ѧ, ꙗ҆́ко ᲂу҆го́дно тєбѣ̀.
